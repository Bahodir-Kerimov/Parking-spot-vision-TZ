# Parking Spot Vision — Техническое задание и шаблон репозитория

Этот репозиторий предназначен для разработки проекта **«Информационная система определения свободных парковочных мест на улицах города методом компьютерного зрения»**.
В папке `docs/` находится полный текст ТЗ (файл `TZ.md`). Ниже — краткая инструкция по публикации на GitHub.

## Как опубликовать на GitHub

1. Создайте новый пустой репозиторий на GitHub (например, `parking-spot-vision`).
2. Выполните команды (Windows PowerShell/Terminal):
   ```bash
   cd parking-spot-vision-TZ
   git init
   git add .
   git commit -m "chore: add Technical Specification (TZ) and repo scaffold"
   git branch -M main
   git remote add origin https://github.com/Bahodir-Kerimov/parking-spot-vision.git
   git push -u origin main
   ```
3. Замените ссылку ниже на настоящую ссылку вашего репозитория.

> ⚠️ **Временная ссылка-плейсхолдер:** https://github.com/Bahodir-Kerimov/parking-spot-vision
